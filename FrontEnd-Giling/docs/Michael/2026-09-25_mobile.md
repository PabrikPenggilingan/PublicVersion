# Mobile UI Fixes & Refactoring - 2026-09-25

## 1. ProcessDetail.tsx (Penggilingan)
- **Visual Workflow Layout**: Changed the "Alur Penggilingan" to display as a 2x2 grid (`grid-cols-2`) on mobile devices, matching the standard set by the Pengeringan module.
- **Finalisasi Modal Overflow**: Fixed horizontal overflow issues by adding `flex-wrap` and replacing fixed-width inputs with responsive widths (`w-full sm:w-...`) in the completion modal.
- **Stats Dashboard**: Reconfigured the 4 metric cards (Input Gabah, Total Output, Rendemen, Penyusutan) to display in a 2x2 grid on mobile, while scaling down their icon sizes and text sizes to prevent bulkiness.

## 2. SalesDetail.tsx (Penjualan)
- **Header Layout**: Adjusted the header layout to wrap gracefully on smaller screens.
- **Tab Navigation**: Enabled horizontal scrolling (`overflow-x-auto`) for the "Item Produk", "Pembayaran", "Transportasi", etc., tabs to prevent horizontal stretching of the page layout.
- **Layout Gap Issue**: Eliminated the massive white-space gap above "Ringkasan Biaya" on mobile by scoping the `min-h-[400px]` rule exclusively to desktop (`lg:`).

## 3. FinanceDashboard.tsx (Finance)
- **Card Resizing**: Reduced the padding (`p-5` -> `p-4`), corner radii (`rounded-3xl` -> `rounded-2xl`), and text sizes across metric cards to optimize screen real estate on mobile devices.

## 4. DryingDetail.tsx (Pengeringan)
- **Responsive Inline Styling**: Replaced hardcoded inline styles (`style={{ backgroundColor: ... }}`) on metric cards with arbitrary Tailwind classes (`md:bg-[...]` and `md:text-[...]`). This ensures the vibrant colored backgrounds and text only appear on medium screens and larger, maintaining a clean default look on mobile.

## 5. Dashboard.tsx (General)
- **Stats Grid Adjustments**: Modified gaps (`gap-4 md:gap-6`) and scaling rules for icons and fonts so they display cleanly on smaller screens.
- **Timeline Scaling**: Updated `TimelineNode` elements for better responsive rendering on mobile views.

## 6. Global Layout Bug Fixes
- **Vertical Scroll Lock**: Reverted a bug where adding `overflow-x: hidden` to `html, body` (to prevent horizontal swiping) inadvertently locked vertical scrolling on certain mobile browsers.
